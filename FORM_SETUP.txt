UK CAD Studio - Contact Form Setup
==================================

This project is now prepared for Formspree and no longer depends on PHP.
That is important because the site is hosted on Vercel, where the old
send-mail.php setup was not working.

TO ACTIVATE THE FORM
--------------------
1. Create a Formspree account.
2. Create one form in Formspree.
3. Copy the endpoint. It looks like:
   https://formspree.io/f/xxxxxxxx
4. Open script.js.
5. Near the Contact form section, find:
   var FORMSPREE_ENDPOINT = 'PASTE_FORMSPREE_ENDPOINT_HERE';
6. Replace only PASTE_FORMSPREE_ENDPOINT_HERE with the full Formspree URL.
7. Save, upload/push the project to GitHub, and let Vercel redeploy.

All project enquiry forms and newsletter forms will then use the same
Formspree inbox.
